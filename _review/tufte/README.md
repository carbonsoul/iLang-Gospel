# iLang Gospel 阅读版改造

39 篇文章现在共用 Tufte 式阅读版面。桌面把经文出处排在引文右侧，手机用同一个编号展开出处。首页把文章、经文位置和 iLang 机制并排显示。英文正文、引文和粗体使用随站分发的 ET Book。

## 阅读与来源

- 进入首页可以从第 001 篇开始，也可以切换三组经文与机制，或用全文搜索定位文章。目录由 Jekyll 自动生成。
- 首页所列 39 条出处和机制逐项对过对应 Markdown。39 篇文章与 Theology Map 合计检查了 68 条旁注，每条均可在关闭脚本的原引文中找到。具备出版行的 17 篇保留了日期和 Blogger 链接。第 004 篇保留 Post ID。
- 后期文章有的仅提供文章号。第 039 篇的开篇经文得到题记排版，正文里的协议引文保持原位。每篇目录取自实际存在的 H2，前后篇取自文件顺序。规范编号沿用正文原文。
- 浅色纸面是浅色环境的默认值；系统深色自动切换。读者可以手动选择浅色或深色，选择会在重新载入和翻页后保留。中文文档使用本机字库。

## 改动位置与授权

- `index.html`、`_includes/archive-entry.html`、`assets/home.css`、`assets/essay-search.json` 提供首页、引用对照、目录和按需全文索引。
- `_layouts/article.html`、`assets/reader.css`、`assets/reader.js` 提供文章、目录、出版信息和响应式旁注。
- `_includes/book-head.html`、`_includes/masthead.html`、`assets/site.css`、`assets/theme.js`、`assets/bookmark*.svg` 提供主题与通用导航。`404.html`、`_layouts/reference.html` 及 `_config.yml` 将其他公开阅读页接入该版式。
- `DESIGN.md`、`DESIGN-BRIEF.md` 和 `PRODUCT.md` 记录新版排版及自动发现文章的方式。授权清单列明 Tufte CSS 和 ET Book 的来源、提交号、原字体文件名和两份独立 MIT 许可。[第三方授权清单](../../assets/tufte/NOTICE.txt)
- 源稿没有明确经文出处时，保留原段文字。评奖结果、实体手机和真实访客性能没有纳入本次测量。
