Read with an agent

The included MCP server brings the collection into compatible clients. It reads the local essays and reference texts using six tools.

Read the connection guide

python3 mcp_server.py

Run from the repository directory. Python 3, standard library only. The server uses stdio and waits for an MCP client; HTTP mode is not implemented.
