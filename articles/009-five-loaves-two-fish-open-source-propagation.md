## The Scarcity Lie

Consider HTTP. If Tim Berners-Lee had charged a licensing fee for every web server that implemented the protocol, the web would not exist. He gave it away. The protocol became the infrastructure. The infrastructure became the economy. The economy made everyone richer — including the people who gave the protocol away for free.
